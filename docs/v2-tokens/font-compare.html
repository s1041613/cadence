字體組合比較

同一個版型、同一組 v1 顏色，只有字體不同

放大對照

同樣的內容，左邊 JetBrains Mono、右邊 Zen Kaku Gothic New。標題（Instrument Serif）兩組相同，所以不列。

兩組的實際差別在哪。標題都是 Instrument Serif，所以差異全在「數字和小字」這一層：

A 組（Mono）的數字等寬，日期在格子裡會嚴格對齊，1 和 7 佔一樣寬。小寫字母帶點技術感，星期列和底部標籤讀起來像標籤而非文字。

B 組（Zen Kaku）的數字是比例寬度，1 比 8 窄，日期對齊會鬆一些。整體更接近一般 UI 字體，中日文字形支援完整（Zen Kaku 本來就是日文字體）。
一個要注意的：Zen Kaku 沒有 600 字重。它只有 300/400/500/700/900。設 600 會由瀏覽器合成，或直接落到 500 或 700。 上面切到 600 時 B 組看起來會跟 500 或 700 一樣 —— 這不是渲染錯誤，是字體本身就沒有那一階。A 組的 JetBrains Mono 則 400 到 800 都有。
