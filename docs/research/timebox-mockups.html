Ⅰ

Plan

Inbox 拖上時間軸，落地即成盒

Timeboxing 的核心動作只有一個：把 to-do 搬進行事曆。Inbox 收合成 Day 視圖底部的抽屜，任務 chip 直接拖上時間軸——放開的瞬間，任務獲得起訖時間，變成一個盒子。

  • 1拖曳即排程。chip 抬起時微微傾斜、帶 overlay 陰影（沿用 --cd-shadow-overlay），時間軸上同步出現落點虛線框。
  • 2估時換算長度。落點框的高度由 estimatedPomodoros 換算（2 顆 ≈ 55 分），使用者可再拉伸；貼齊 5 分刻度，與 time-wheel spec 的顆粒一致。
  • 3四象限決定順序。chip 左側的色點是象限色——Inbox 依「馬上做 → 排時間做 → 快速處理」排序，提示先給誰盒子。

資料模型零異動：寫入的是 Task.date / start / end 既有欄位。

Do

盒子到點，番茄鐘接手

排程（計畫盒）直接餵給既有的 Focus 番茄鐘（執行盒）。盒子開始時提醒一次，預覽卡多一顆「開始 Focus」按鈕；完成的番茄自動回填 completedPomodoros，這個欄位從此不用手填。

  • 1到點輕推，不打斷。用 toast 提示盒子開始了，一鍵進入 Focus；不自動開跑——開始永遠是使用者的動作。
  • 2番茄進度即盒子進度。實心點 = 已完成（自動回填），空心點 = 剩餘預估。預估 vs 實際從這裡開始累積。
  • 3軟盒哲學。沿用番茄鐘現成的超時背景變色：時間到只變色提醒，不強制切斷——盒子是提醒者，不是鬧鐘警察。

接線點：focus-store 增加 taskId 綁定；計時真相仍在絕對時間戳 reducer，不動。

Review

週 = 個人 sprint，預估 vs 實際

有了前兩段，回顧幾乎免費。Week 視圖頂端加一張唯讀摘要卡：本週預估幾顆、實際完成幾顆、差在哪幾天、哪個任務常態爆估。這是使用者估時能力的校準器，也是別的 app 帶不走的歷史資料。

  • 1兩個數字就夠。預估與完成並排，serif 大字沿用海報標題的字面；不做儀表板，一眼讀完。
  • 2每日雙條。灰條 = 預估、橄欖條 = 實際，七天並排；哪天計畫崩了一眼可見。
  • 3點名爆估者。單一任務的實際／預估比超過 1.5× 就點名——下次給它更大的盒子，或拆小。

先做唯讀統計：資料全部來自 estimated / completedPomodoros，一個 computed 就能出。

Life

縮放階層的最後一層：人生週曆

Day → Week → Month 之上再加一層 Life：一列一年、52 格一列的海報，視覺語言直接延續月曆海報（Instrument Serif 標題、格狀、留白）。它不催你做更多，它讓你選擇——這一格人生要花在什麼上。

  • 1一格 = 一週 = 一個 sprint。已過的週上墨、未來留白；當前格用 --cd-accent-strong 呼吸微閃（respects reduced-motion）。
  • 2當前格點下去就是 Week 視圖。宏觀與微觀用同一個手勢接起來：這格人生的內容，就是你這週排的盒子。
  • 3人生事件落格。用既有事件色在格子上留點（畢業、搬家…），海報慢慢長成人生年表。

需要的新資料只有一個：birthDate（settings）。格子全部由它推導。
