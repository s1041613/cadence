Cadence · Notebook · 設計稿

便條加上資料夾

現在的 Notebook 是一條沒有盡頭的時間軸：所有便條依寫下的時間新到舊排列，只能往下捲找。 便條一多，「上週那個點子」就等於找不到。這份設計把參考畫面裡的分頁式分類搬進 Cadence—— 頁首下方一排資料夾分頁，最右邊的 ＋ 開新資料夾，新增便條時就決定它落在哪一格。

參考畫面是深色、圓角、粉紅重點色的清單 app；這裡只借它的資訊結構（分頁列 ＋ 尾端新增 ＋ FAB 新增）， 外觀維持 Cadence v2 既有的語彙：#fafaf9 畫布、白色點紙卡片、JetBrains Mono、黑色 64px FAB。 分頁藥丸直接沿用 Pv2Chip 的黑底 / 描邊兩態，FAB 沿用 Pv2Fab，面板沿用 Pv2DaySheet 的圓角與把手。

一個新增手勢

現有的「速記藥丸」由 FAB ＋ 底部面板取代，跟 Day / Month 的新增方式一致，也對齊參考畫面。面板一打開就聚焦、Enter 直接存檔，少掉的那一次點擊由此補回。

分頁只放文字

emoji 留在資料夾清單與管理頁；分頁列以密度優先，一屏能露出四到五個資料夾。名稱右邊的數字是該資料夾的便條數，順手也回答了「這裡是不是空的」。

永遠有地方可去

全部固定在最左邊、不能改名或刪除；沒有指定資料夾的便條落在未分類。刪掉資料夾時便條不會跟著消失，一律退回未分類。

要動到的東西

這份設計是視覺提案，不是實作規格；下面只列出它必然牽動的既有檔案與行為，方便估工。

位置需要的改動
src/types/note.ts 便條多一個 folderId: string | null；null 就是「未分類」，所以既有便條不必資料遷移，也不必先建一個實體資料夾。
新增 note_folders 使用者層級的資料夾：id、name、emoji、sortOrder。刪除時把該資料夾的便條 folderId 設回 null（不是連帶刪除）。
notebook-store.ts 沿用既有的樂觀寫入 ＋ 逐 id 佇列模式：新增 addFolder / renameFolder / removeFolder / moveNote，選中的分頁是本機 UI 狀態，不進 DB。
NotebookViewV2.vue feed 改成依選中的資料夾過濾（全部 不過濾），排序邏輯不變：仍然嚴格以 createdAt 新到舊。
Pv2NoteComposer.vue 速記藥丸退場，改為 Pv2Fab ＋ 底部面板；面板內文欄位與資料夾藥丸同一列工具列。
Pv2NoteCard.vue 右上角的垃圾桶收進長按選單；在「全部」時多顯示一顆資料夾標籤。

還沒決定的

  • 資料夾要不要有數量上限？分頁列一屏約放得下四到五個，超過就只能靠橫捲找，十個以上會開始難用。
  • 「全部」要不要記住上次選的分頁？記住對常用單一資料夾的人比較順，但每次回來看到的畫面就不一定相同。
  • 便條要不要能同時屬於多個資料夾？現在的設計是一則一格——若要多對多，分頁列的語意就得從「資料夾」改成「標籤」。
