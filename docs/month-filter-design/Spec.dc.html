Cadence · Month view

行事曆 / 待辦 顯示切換器

一個三段式玻璃 segmented control，只管月曆格線畫什麼：全部、只看行事曆（type === 'event'）、只看待辦（type === 'quadrant'）。玻璃配方直接沿用 Pv2BottomNav 的底座與滑塊，不是新的一套語彙。

玻璃配方（沿用，不是新增）

/* 底座 —— 與 .pv2-nav 同一組值 */ border: 1px solid rgba(255,255,255,.55); background: linear-gradient(180deg, rgba(255,255,255,.72), rgba(255,255,255,.46)), var(--pv2-canvas); backdrop-filter: blur(22px) saturate(140%); box-shadow: var(--cd-shadow-overlay); /* 滑塊 —— 與 .pv2-nav__pill 同一組值 */ background: linear-gradient(160deg, rgba(255,255,255,.55), rgba(255,255,255,.18)), rgba(var(--pv2-accent-rgb), .12); backdrop-filter: blur(14px) saturate(160%); transition: transform var(--cd-duration-glass) var(--cd-ease-glass); /* .42s / 彈性回彈 */

不支援 backdrop-filter 時退回不透明底（@supports not），與 nav 相同的處理。prefers-reduced-motion 時滑塊不做位移動畫，只換顏色。

三個狀態
全部（預設） aria-label="全部"

格線畫所有項目，與現在完全一樣。

只看行事曆 t.type === 'event'

圖示直接沿用 nav 的 month 字符 —— 在這個 app 裡那個形狀已經代表「行事曆」。

只看待辦 t.type === 'quadrant'

格線只剩四象限色。上面兩張 TASKS 卡不受影響 —— 它們本來就只講待辦。

程式落點
ui-store / settings-storemonthFilter: 'all' | 'event' | 'quadrant' MonthViewV2.vuegridWeeks 的 visible 多一層 filter 新元件Pv2TypeSwitch.vue

// MonthViewV2.vue — 唯一的資料改動 const visible = tasksStore.tasks.filter( (t) => calendarsStore.isVisible(t.calendarId) && matchesFilter(t) // ← 新增這行 )

日檢視、週檢視、Pv2DaySheet 不吃這個 filter：一格點下去還是看得到那天的全部內容，否則會有「東西不見了」的錯覺。

無障礙
  • 純圖示，所以每段一定要有 aria-label；role="group" + aria-pressed。
  • 點擊區 44 × 44，圖示 20px 置中 —— 視覺高度 36，靠上下 4px padding 補到 44。
  • 選中只靠粉色滑塊，色差對淺底約 1.2:1。這是這個設計最大的風險：色盲或強光下可能看不出選中的是哪一段。要補的話，選中那段的圖示改 stroke 2.2，用線寬再講一次。
