顯示切換器

兩段式玻璃控制，浮在月份大標題上方、右對齊 —— iOS Notes 放資料夾 / Edit 按鈕的那一排。它只管月曆格線畫什麼：全部，或只看行事曆（type === 'event'，把待辦收起來）。已實作於 Pv2TypeSwitch.vue。

高度 36 不是 44：月曆一頁的高度是有限的，標題區每多一 px 都是從 grid 的 lane 預算扣（month-lanes.ts 的 ROW_MAX_H）。44 的點擊區用 ::after 撐出去，不佔版面。靜止色用 --pv2-ink-2 而不是 nav 的 --pv2-ink-3：這顆可能落在桌布上，提示灰抓不住照片。

為什麼白板留著

上面兩張是純透明版（沒有白板），左邊有桌布、右邊是 app 現在的預設白底。玻璃要有東西可以折射才存在 —— 白底上它只剩一圈白邊。而 v2-appearance-store.ts 是 backgroundImage: null（預設沒桌布）、DEFAULT_SCRIM_OPACITY = 0.8（就算設了桌布也洗到接近白）。所以出貨的是帶白板那版：在兩種情況下都讀得出來，勝過只在一種情況下漂亮。Canvas 第二頁留著純透明版的四張對照。

ui-store.tsmonthFilter: MonthFilter（不同步，重整回 all） MonthViewV2.vue.mv2__topbar + matchesMonthFilter Pv2Poster.vue--pv2-poster-pad-top，預設 30px 新元件Pv2TypeSwitch.vue

// MonthViewV2.vue — 唯一的資料改動 const visible = tasksStore.tasks.filter( (t) => calendarsStore.isVisible(t.calendarId) && matchesMonthFilter(t) )

日檢視、週檢視、Pv2DaySheet 不吃這個 filter：一格點下去還是看得到那天的全部內容，否則會有「東西不見了」的錯覺。上面兩張 TASKS 卡同理不受影響 —— 它們本來就只講待辦。

還沒解決的
  • 兩段只能「把待辦藏起來」，沒有「只看待辦」。要的話第三段隨時可以加回來：OPTIONS 多一筆，控制元件從 90 變 132，其他都不用動。
  • 高度預算很緊。5 週的月份 + home indicator 時，grid 距離三 lane 的天花板只剩個位數 px；6 週的月份本來就是兩 lane（改動前就是）。真的擠掉了就把 --pv2-poster-pad-top 再收一點。
  • 純圖示，每段一定要 aria-label；role="group" + aria-pressed。
  • 選中只靠粉色滑塊，色差對淺底約 1.2:1。色盲或強光下可能看不出選中哪一段 —— 要補的話，選中那段的圖示 stroke 從 1.7 加到 2.2，用線寬再講一次。
