玻璃配方 —— 沒有白底

/* 底座：模糊 + 邊緣高光就是全部的材質 */ border: 1px solid rgba(255,255,255,.5); background: rgba(255,255,255,.06); /* 幾乎不填 */ backdrop-filter: blur(20px) saturate(180%); box-shadow: inset 0 1px 1px rgba(255,255,255,.70), /* 上緣受光 */ inset 0 -1px 1px rgba(255,255,255,.28), /* 下緣反光 */ 0 6px 20px rgba(40,38,30,.14); /* 滑塊：粉色本身就是材質，不疊白 */ background: rgba(var(--pv2-accent-rgb), .20); backdrop-filter: blur(10px) saturate(160%); transition: transform var(--cd-duration-glass) var(--cd-ease-glass); /* .42s 彈性 */

與 Pv2BottomNav 的差別只有一處：nav 疊了 linear-gradient(rgba(255,255,255,.72) → .46) 的白板，這顆拿掉了。動畫曲線、邊框、陰影都照舊。

圖示沿用 nav 的 month 字符 —— 在這個 app 裡那個形狀已經代表行事曆。

透明玻璃的前提

同一顆，左邊有桌布、右邊是 app 現在的預設。玻璃要有東西可以折射才存在 —— 白底上它只剩一圈白邊。而 v2-appearance-store.ts 現在是 backgroundImage: null（預設沒桌布）、DEFAULT_SCRIM_OPACITY = 0.8（就算設了桌布也洗到接近白）。要讓這個設計成立，白紗要壓到 0.35 上下。兩條路：把控制元件跟桌布綁在一起（沒桌布就退回 nav 那種帶白板的玻璃），或是把預設白紗調淡。

日檢視、週檢視、Pv2DaySheet 不吃這個 filter：一格點下去還是看得到那天的全部內容，否則會有「東西不見了」的錯覺。上面兩張 TASKS 卡同理不受影響 —— 它們本來就只講待辦。

還沒解決的
  • 兩段只能「把待辦藏起來」，沒有「只看待辦」。要的話第三段隨時可以加回來，控制元件從 96 變 140。
  • 純圖示，每段一定要 aria-label；role="group" + aria-pressed。
  • 選中只靠粉色滑塊，色差對淺底約 1.2:1。色盲或強光下可能看不出選中哪一段 —— 要補的話，選中那段的圖示 stroke 從 1.7 加到 2.2，用線寬再講一次。
